# RAG Support Assistant

A document-grounded question-answering system with source citations,
retrieval evaluation, and classical machine learning for support tickets.

## Planned Features

- Document ingestion and cleaning
- PII detection and redaction
- Fixed-size, recursive, and heading-aware chunking
- Dense, BM25, and hybrid retrieval
- Local LLM answer generation with citations
- Golden evaluation dataset and retrieval metrics
- Support ticket classification
- FastAPI service, testing, and Docker deployment

## Technology Stack

- Python
- Hugging Face datasets and models
- Sentence Transformers
- Qdrant or PostgreSQL with pgvector
- FastAPI
- scikit-learn
- MLflow
- Docker
